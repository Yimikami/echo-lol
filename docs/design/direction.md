## Direction contract
THESIS: Let a player find a moment, watch it, and export a deliberate range without leaving the library.
OWN-WORLD: Graphite surfaces, warm-white copy, mint selection and coral death markers. Thin separators, compact media rows, restrained native controls.
STORY: Recorder status stays peripheral; the selected recording owns the screen. Search and event filters narrow the list.
FIRST VIEWPORT: Header at 8% height, left navigation at 13% width, clip list to 41%, player fills the right, and trim controls span the bottom.
FORM: Media catalogue, grounded candidate 4, seed 9840a467. User selected C after seeing all three comps. Motion and inversion challengers were declined because always-on effects conflict with quiet gaming software; their density discipline informs alignment, not decoration.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Translation boundaries: use actual clips, timestamps and thumbnails. Empty state replaces illustrative game images when no clips exist. This WPF desktop surface uses native keyboard and resize behavior; HTML-specific tooling does not govern its implementation.
